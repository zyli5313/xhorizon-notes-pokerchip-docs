---
title: "Planning Starting Stacks"
description: "How to choose colours, size each seat's starting stack, and plan colour-ups so a home game night runs without constant change-making."
---

A starting stack is the pile each seat receives before the first deal. A good one lets every player keep making small moves through the night with no need to split a big chip, and it is quick to hand out.

## Choose how many colours

Fewer colours mean fewer values to remember. Three cover most casual tables; a fourth helps only with large stacks.

When you assign values, keep neighbouring colours close together. A step from 5 to 25 works; a step from 5 straight to 100 means someone breaks a large chip every few minutes. The reference on [what each chip colour is worth](https://pokerchip.live/faq/what-is-each-poker-chip-color-worth) explains why the ratio between adjacent colours matters more than the exact numbers, and why any agreed set of values is fine as long as it is settled before play starts.

## Size the stack by seat

Work from the people, not the plastic:

1. Fix the total points each seat starts with.
2. Give each seat about twenty of the smallest colour.
3. Fill the rest of the total with the next colours up, using fewer chips of each as the value rises.
4. Multiply by the number of seats and confirm your counted totals cover it.

An example for six seats, each starting with 500 points, using white 1, red 5 and green 25:

| Colour | Value | Per seat | Points per seat | Needed for six seats |
| --- | --- | --- | --- | --- |
| White | 1 | 25 | 25 | 150 |
| Red | 5 | 15 | 75 | 90 |
| Green | 25 | 16 | 400 | 96 |
| **Total** | | **56 chips** | **500** | **336 chips** |

A standard 500-chip case covers this with room to spare, as long as it holds at least 150 white chips.

## Plan the colour-up

As an evening goes on, the smallest chips become less useful. A colour-up swaps them for the next colour so stacks stay manageable.

- Announce it one round before it happens so nobody is surprised.
- Exchange whole groups first: five whites for a red, five reds for a green.
- Put the retired colour back in the case at once so it does not drift back into play.

The reserve set aside while counting is what makes this possible.

## Pre-build the piles

Build one stack per seat before guests arrive, using the same stack-of-twenty method from [Counting a Chip Set](/counting-a-chip-set). Identical piles, set out at each seat, mean the first hand starts on time and every seat begins level. If the night runs on phones instead, [PokerChip.live](https://pokerchip.live/) hands out the same starting stack to every player as they join, and the totals stay visible to the whole table.

Counting chip by chip is slow and error-prone. Counting in stacks of a fixed height is fast, and the goal is one written total per colour you can trust for months.

## Count in stacks of twenty

Pick a stack height and stick to it. Twenty is convenient because two stacks make forty, five make a hundred, and a stack of twenty is still steady on a soft tablecloth.

1. Tip one colour onto the table and leave the others in the case.
2. Build stacks of twenty. Line them up edge to edge so a short stack stands out.
3. Count the stacks, multiply by twenty, add the loose remainder, and write the total on a card kept inside the lid.
4. Repeat for each colour. A 500-chip case usually takes eight to ten minutes.

<Tip>
Tape the inventory card inside the lid with the date. When something goes missing you only need to recount the colour that looks short, not the whole case.
</Tip>

## Run the coverage check

Once you have totals, check that the case can actually serve the number of people coming. The [chip calculator](https://pokerchip.live/poker-chip-calculator) does this directly: enter the seats, the starting stack, and how many chips of each value you own, and it reports whether the case covers everyone and how much value is left over for colour-ups.

On paper: multiply the chips per seat in each colour by the number of seats and compare with your written totals.

The colour that runs out first is almost always the smallest one, because every seat needs a lot of it. Starting guidance on [how many chips each player gets](https://pokerchip.live/faq/how-many-chips-does-each-player-start-with) puts the smallest chip at roughly twenty per seat, regardless of how large the overall stack is.

## Common counting mistakes

- **Counting a mixed pile.** Sort everything first, then count one colour at a time.
- **Trusting the box label.** A "500 chips" case may hold 150 of one colour and 50 of another. Only your own count matters.
- **Forgetting the reserve.** Keep roughly a fifth of the case aside for late arrivals and colour-ups.

## When the case is too small

If the check fails, raise every colour's value so fewer chips make the same stack, or move the stacks onto phones.
